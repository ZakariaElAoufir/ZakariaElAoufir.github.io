Démo Architecture Code

Le problème

Les fiches techniques agricoles (FAO, INRA, ONSSA) sont longues et dispersées : trouver la bonne dose d'irrigation ou le bon stade d'intervention demande de lire des dizaines de pages.

Ce que fait l'application

On pose une question agricole en français. AgriGPT cherche les passages pertinents dans les PDF, fait rédiger la réponse par un modèle local (Ollama), cite les documents utilisés et garde l'historique, exportable en PDF.

Mon rôle

Projet réalisé seul : ingestion des PDF, index FAISS, API FastAPI, filtre du domaine agricole, base SQLite et interface Streamlit.

Simulation : données fictives. Les réponses sont préenregistrées à partir des vrais documents du projet ; aucun modèle d'IA n'est appelé.
